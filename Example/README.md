## This is a example folder that has pyGSM calculation combined with ASE and AIMNET2
## This calculation requires the installation of pyGSM in the conda environment using the provided zip file
## The input files are:
# 1. Product xyz file (conf.xyz)
# 2. Atom indices of where bonds are broken or formed (isomer.txt)
# 3. submission script (submit.sh)
# 4. external forces (3xN dimensions) (constraints.txt)
# 5. a python file that can convert the output of single-ended GSM to input geometry of double-ended GSM (convert_conf.py)
# 6. Run GSM (test.py)
